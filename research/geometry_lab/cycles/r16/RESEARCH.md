# R16 — cut-disk harmonic UV feasibility, preregistered before execution

R15 showed that the old source collars inherit invalid wrapped UV edges. Here the source UV is independently authored from the original input loops BEFORE generating the R10 strip. This is a limited detached-strip feasibility experiment, not a real asset or Blender operator test. No source UV mutation is allowed.

Candidate: sort each input loop CCW by its existing traversal direction, rotate to its max-X vertex, use normalized cumulative 3D perimeter lengths for U=0..1, lower V=0 and upper V=1. Each loop has an explicit 0/1 seam at the anchor; values are per edge/corner, not one UV per geometric vertex. Compute a shortest interior edge path between the anchors without traversing other boundary vertices. Cut only that path by splitting corner equivalence classes; fix boundary UV pins exactly and assign each seam side U=0 or 1, V by normalized path arc length. Uniform positive graph-Laplacian harmonic solve for free chart vertices. Reject incompatible, nonmanifold, degenerate, non-disk, conflicting, nonmonotonic or unsolved cases; no forced repair, no source edits. R14 audit independently measures overlap, mixed winding and degeneracy, and CGAL checks the unchanged detached R10 strip. The candidate only supports these rectangular boundary charts, not arbitrary source UV layouts.

Comparator: legacy angular modulo U seed with exact independent boundary corners overwritten (naive baseline, NOT frozen R13). Measure overlap, seam count, winding and anisotropy for both. The main gate does not require beating R13 because its source UV inputs are incompatible.

4 seen R13 geometries for development and 8 newly authored frozen holdouts. Four explicit negative controls on seen geometries: missing edge, contradictory UV pin, wrapped/nonmonotonic boundary and nonfinite source pin. Gate: every fresh case preserves boundary UV within 1e-8; zero positive-area overlap pairs at 1e-9 threshold, zero mixed-winding islands, zero degenerate UV faces at R14 threshold, exactly one UV island and actual internal seams exactly the cut path; detached CGAL 0 and exact 3D arrays unchanged. All four bad inputs rejected. Report old R10 geometry quality separately; do not count UV pass as geometry-quality pass. Do not retune on fresh cases. No claim of 2D exact predicates, general UV packing, assembled mesh, Blender Edit Mode, shading or real-model quality. Only research scope, approved=false, no R17 automatic start.
