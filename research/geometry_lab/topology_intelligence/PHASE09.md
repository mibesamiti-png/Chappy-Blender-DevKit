# Topology Intelligence — phase 09

Independent planar structured quad-strip benchmark; semantic row tags and persistent vertex IDs, boundary-chain extraction from edge incidence, extrusion and transverse midpoint subdivision with inherited tags. Four width ratios, three extrusion heights, zero/one/two splits, five deterministic shuffle seeds: 180 cases. Vertex-list and face-list reordering preserves selected persistent IDs 180/180; stale pre-shuffle indices select the correct complete set 0/180 in this stress test. Post-shuffle extrusion matches unshuffled control geometry/connectivity 180/180. Four rejected edits per case: negative extrusion height, missing semantic selection, collapsed tip, duplicated face; 720/720 restore complete in-memory snapshot including ID allocator. Checks include unique IDs, finite coordinates, quad convexity/orientation, edge incidence, disk Euler characteristic, connected boundary and tip chain. Synthetic script, JSON, six stage OBJs and actual plotted preview packaged locally with ZIP CRC check.

Limits: structured planar strips only; semantic roles explicitly propagated by custom operators, not inferred from arbitrary imported geometry. Split relies on stored face-corner convention; shuffle changes vertex and face ordering, not cyclic face-corner order. Selection uses x coordinate for chain orientation. Stale index baseline intentionally invalidated; not comparison with Blender's actual selection system. Snapshot rollback is not a complete undo/redo or crash recovery engine; no general self-intersection checks, native Blender/BMesh, arbitrary 3D branching, or performance validation. No private reference data used or published. No product adoption, main/ABCD/DIL changes, approved=false. Next test branching semantic selection, ambiguity handling and topology-changing local edits in 3D.
