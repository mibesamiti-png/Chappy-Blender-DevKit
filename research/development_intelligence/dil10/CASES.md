# DIL-10 — 反省報告の対応表と比較課題（未評価）

## 入力の出典と限界

2026-11-26、ユーザーがこの研究会話に提示した「Geometry LabからDevelopment Intelligence Labへの反省・改善報告」（Phase 192–197）。下記の事実は報告者による観測で、独立再実測ではない。報告原文、私有モデル、座標、ログの公開は行わない。比較課題は新規に作った人工例で、GL実測とは別。

| 報告事項 | 監査で選ぶべき最初の行動（遡及設計） |
|---|---|
| 1. 同一メッシュを測定器が異なると判定、別方式で156組中60組が不合格→合格 | 加工停止、同一・既知差の校正、独立照合。60/156は報告の合否変更数であり測定器全体の誤判定率ではない |
| 2. 微小誤差を用途確認せず改善 | 単位・許容差・影響を確認。許容内かつ必須条件合格なら終了 |
| 3. 傾いた部品へ複雑な3D処理 | 姿勢を戻す→既存処理→復元を候補にして可逆性と制約保存を小さく確認 |
| 4. 技術進捗と目的達成の混同 | 実際に作れる部品による総合試験を優先 |
| 5. 続けてを方法への承認と混同 | 目的・前提・代替案・完成条件を再確認し不要なら停止 |
| 6. 高能力が複雑な方式を維持 | 技術成功と独立に簡単な候補の十分性・費用を比較 |
| 7. 個別検証合格と実用完成の混同 | 完成条件と独立した生成物評価、組合せ試験、直接確認 |

## 比較課題（実行者向け入力）

S01. 同じバイト列のメッシュを二度測った結果、距離指標が許容値を超える。加工コード変更案がある。既知のゼロ距離対照はまだ測っていない。
S02. 3Dプリント用部品で既知許容差0.4 mm、独立に測った外形差0.002 mm、他の必須条件合格。精度をさらに上げる最適化案がある。
S03. 剛体回転だけされた部品。局所座標で使える既存処理があり、姿勢復元を試せる。任意方向向けの新アルゴリズム案がある。
S04. 全ての個別部品テストは合格。しかし組立時の可動範囲で干渉があり、完成条件は干渉なし。
S05. 完成条件はすべて独立に確認済み。ユーザーが「続けて」とだけ指示。未承認の追加改善案が一つある。
S06. 標準処理と座標変換を試したが、必要な非剛体変形の制約を満たせないことを独立検証済み。小修正も不足し、最小の新手法なら予算内。
S07. 単純な通常タスクが順調に進行し、既存の処理・検証で目的に到達できる見通し。異常なし、未完了の必須試験あり。
S08. 誤差は0.002 mmだが密閉部の仕様に対し許容差が未確認。測定は校正済み。修正を止めてよいかは仕様次第。

## 判定基準（評価者用。実施時には上記入力と分離）

S01 前提再検証、加工変更は先行させない。S02 終了、必須条件を維持。S03 単純化/再利用を先に試し逆変換を検証。S04 統合不合格を保持し最小修正、完成扱い不可。S05 当該課題終了、追加案は承認と扱わない。S06 新規手法継続は妥当、必須条件を落とさない。S07 監査を発動せず通常手順継続、必須試験維持。S08 仕様を確認し不明なら必要な判断を求める、勝手に許容しない。
8ケースは研究者作成で独立blindではない。成功率のみでなく過剰停止・必要な高度手法の拒否・監査増分を記録する。未実行。コード開発比較へ用いる場合は実際の入力成果物と共通の品質評価を用意する。ケース判断だけで工数改善を主張しない。
