## Producer contract for A

Allocate a fresh lowercase 32-hex run_id per case invocation in the trusted parent (for example uuid.uuid4().hex). Pass the same expected case, exact target version and run_id to reduce_stage_records; never choose expected identity from the input records. Cases: read/edit/grouped. Exact versions: 4.4.3/4.5.15/5.2.1. Stage order: generation, validate, enable, operation, cleanup, sha_unchanged. Each record is a plain object with exactly case, blender, run_id, artifact_sha256, stage, status, reason, diagnostic. Status is passed, failed or not_run. reason/diagnostic are null for passed and not_run. The producer records the actual generated root ZIP SHA256 (64 lowercase hex), not the input recipe or preview ZIP SHA, and independently compares actual stage artifact bytes with the expected digest. If a digest differs, do not overwrite it with the expected value to manufacture agreement. Every row carries the same generated digest after successful generation; if generation fails all rows have null digest.

Record each real observation only after its corresponding gate completes. Validate success requires actual process exit zero plus accepted, complete local/official diagnostic agreement (official_validate_observation reuses existing comparator). Enable requires native namespace/registered-state observation, operation requires real expected results, cleanup requires actual disable/ledger checks, sha_unchanged requires post-execution byte comparison. Do not infer separate positive stage records from merely seeing a combined success marker or rebuild an artificial record from unrelated runs. C's Undo experiments and their GUI boundary are separate: the reducer does not certify Undo, natural history, GUI, user scenes, official install or rights. A must connect C to the same registered grouped artifact.

On failure set reason exactly per stage: generation_rejected, validate_failed, enable_failed, operation_failed, cleanup_failed, evidence_mismatch. Optional generation diagnostic comes from generation_diagnostic (existing preflight category or fixed fallback); optional validation diagnostic comes from official_validate_observation. Do not forward exception text or raw logs. All later gates are not_run even if emergency cleanup is attempted physically; record that separate safety action outside positive-stage evidence. For a full coherent failed sequence the reducer returns failed; a missing trailing stage is incomplete_evidence, reordered/duplicate/contradictory/unknown rows or identity mismatch are evidence_mismatch. No malformed report can authorize execution. A must treat only verified_fixed_stages as positive consistency evidence; its false authorization/GUI/installer/rights/authentication flags are unconditional. Preserve raw CI logs only within their existing restricted diagnostic workflow, not the public aggregate.
