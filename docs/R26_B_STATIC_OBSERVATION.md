Internal helper cbdk.glb_parameter_static_r26.observe_fixed_parameter_fixture(
run_id=..., source_sha256=..., blender_version=...). A supplies its fresh
32 lowercase hex run ID, SHA of the actual fixed fixture, exact matrix version.
Returns case_id, run_id, source_sha256, blender_version, properties (ordered
sphere_radius, bevel_width); each property has declaration_count,
same_class_self_count, geometry_path_count, expected_api_observed only.
No invented run identity; hash verified before and after existing AST analysis.
SHA is consistency only, not authenticity or permission.

Uses existing diagnose -> repair plan -> property map (inventory, usage,
geometry flow) with explicit test-only category-to-property mapping. Static
counts are syntactic, never RNA registration, readback or causal effect.
The static-only plan uses controlled diagnostic inputs to enumerate both fixed
properties; this is not a claim of actual GLB diagnostic findings.
fixed_diagnostic_candidates(comparison) separately maps ONLY actual matching
target/category pairs from a comparison using existing diagnosis and plan.
No topology diagnosis is inferred from an actual bevel coordinate change.
Unmatched categories remain unmapped. Expected APIs are sphere primitive
and modifier.width, the latter only a syntactic assignment, not an
authenticated modifier receiver. Duplicate declarations preclude a positive
expected_api_observed, duplicate class names reject the observation.
Negative tests: separate receiver, missing path, same-named property in
unrelated class, duplicate declaration, class-name ambiguity, identity/SHA
mismatch, absent or unrelated diagnostic categories. General public rules
and original seven variants, fixture source, C/D/A-owned files unchanged.
A owns same-source/run/version integration with native observations and
strict reducer. B has no native helper execution claim before that integration;
existing 7-variant native marker is a regression, not joined static evidence.
CI pending; no execution of arbitrary source, no auto apply/approval or release.
