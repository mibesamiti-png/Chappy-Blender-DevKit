## Parent adapter (A-owned actual observations)

Call reduce_candidate_evidence(trials, claimed_history, run_id=..., blender_version=..., reference_run_id=..., source_bytes=..., allowed_candidates=..., measured=..., references=..., budget=4). Parent supplies independent fresh R28 run ID and different R26 reference run ID (both lowercase 32 hex), exact Blender matrix version, actual original fixture bytes (pinned R27 SHA), and actual independently checked candidate bytes. allowed_candidates maps fixed trial IDs to bytes; no execution happens in D. Reducer independently derives only fixed substitutions and inverse from pinned source; CRLF or any other byte change is not permitted for execution. Parent additionally checks AST and actual work copies. The sole two-token edit is cross_part; all candidates derive from original, never previous best.

Each ordered trial has the exact fields:
- case_id=parameter_source_r28, run_id, blender_version, source_sha256, reference_run_id, trial_id, candidate_sha256 (lowercase hex derived from actual bytes).
- diff: tokens (ordered sphere then bevel when changed; each property, byte_offset, old_token, new_token), ast_diff_verified, exact_diff_verified, restored_sha256.
- isolated_copy_verified, restoration_verified, original_source_unchanged, reference_sha_unchanged; actual booleans.
- restored_copy_sha256; reference_glb_sha256 (mapping all seven R26 variant IDs to actual file SHA).
- stages: original/candidate/restored, ordered once each. Each stage repeats trial identity and stage, actual_source_sha256, rna_defaults and rna_after_build (both exact sphere_radius/bevel_width float observations, tolerance 1e-6 from expected), registered, cleanup_verified, glb_sha256, generated_mesh, imported_glb_mesh. No extra fields.

measured maps trial ID to a separately observed normalized trial with same fields. This is an adapter shape, not a mandate to duplicate C's raw report schema or copy C assertions. Parent must capture actual source/candidate/restored bytes, registration and readback, mesh and GLB hashes at each stage, validate isolation/cleanup/unchanged reference files and inverse restoration, and derive its own normalized trial. D compares the two normalized observations exactly. Missing actual observations cannot be filled by expected values or markers. Do not normalize raw execution bytes. Static tests alone recognize the exact Windows CRLF checkout and recover canonical fixture bytes in memory as in R27.

references has case_id=parameter_fixture_r26, run_id=reference_run_id, blender_version, source_sha256, variants (all seven same-job R26 variant IDs). Each variant has glb_sha256, generated_mesh, imported_glb_mesh. Each mesh has exactly CBDK_Param_Sphere and CBDK_Param_BevelCube, each with mesh_vertex_count, mesh_polygon_count, mesh_coordinate_sha256, world_dimensions (three positive finite dimensions). Parent obtains real GLB hashes and actual R26 measurement summaries, retains the R27 and all seven R26 outputs, checks them before/after, and binds the actual reference run. D requires original/restored fixed metrics equal baseline; candidate fixed metrics equal the specified sphere/cube reference independently, including cross_part's two distinct references. No mixed GLB is claimed. Distinct stage/reference GLB bytes allowed when fixed measured geometry agrees.

## B history adapter / independent replay

Normalize B's evaluation into claimed_history with exact keys budget (plain int 1..4), rows (ordered list), best_id, stop_reason (target_reached/budget_exhausted/incomplete), target_reached (plain bool). Each row: trial_id, generated_score, imported_score, decision, best_before, best_after. D independently recomputes scores (max absolute dimension difference, two phases, margin 1e-5), then vetoes any protected cube measurement difference first; requires both phases strictly improved or regressed; tie, asymmetric and zero-score-but-mesh-mismatch are uncertain. Full measured target requires matching sphere measurements, both scores within margin and protected cube unchanged. No premature target. Scores in claimed history must agree within 1e-9 and all best transitions/decisions/stop fields must match. No arbitrary code or paths; all reasons fixed.

Expected full trace: wrong_direction -> target_regression/baseline; cross_part -> protected_part_regression/baseline even at score 0; intermediate -> observed_improvement/intermediate; target -> observed_target_reached/target then stop. Complete fixed history is verified_fixed_history. Valid budget-limited trace without target is verified_budget_exhausted with same_fixture_selection_verified false. Prefix budget replay uses already measured observations, never claims physically stopping Blender earlier. Incomplete records cannot certify success and false target/contradictory history is rejected. Malformed/unknown/duplicate/order/type/nonfinite/identity/SHA/restore/independent measurement mismatch is rejected. All safety fields stay false, including auto_apply/auto_adopt/auto_approve and general geometry equivalence.
