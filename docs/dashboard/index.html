● 音が鳴るか試したいときは「♪ 通知音」をONにして「♫ 試聴」をクリック。初回読込済みの完了・すでに通知したラウンドでは鳴らしません。
● 画面を開いている間のみ5分ごとに更新。閉じたタブでは監視しません。通知音は「♪ 通知音」を押して有効化した後に、新しく完了を確認したA/B/C/Dにつき一度だけ鳴ります。初回表示の過去の完了は鳴りません。ブラウザの省電力・音声制限が優先されます。
● 完了 = B/C/Dは担当PRのHEADで5系統CI成功、Aは統合PRのマージ後に別SHAの7系統push CI成功。未実行のCIを成功扱いしません。数字は自動推定を含み、一般ユーザー向け完成・ライセンス承認を意味しません。
● v3の速度値はGitHubのPR created_at / merged_at とActions updated_atから計算します。Actions最終更新は厳密なテスト終了時刻ではないため、BCD完了→Aマージ時間は近似値です。PR/CIが取得できない場合は「―」を表示します。開発着手時刻や作業時間そのものではありません。
● 公開GitHub APIのみ使用。トークン不要・送信データなし。通常の未認証API上限は60回/時。 GitHubリポジトリ / 作業キュー
